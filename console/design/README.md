# Console design source

The approved design source for the new console: the canvas
**Holophyte Console · Final**, approved by the maintainer on 2026-10-14.
The human-facing original is the claude.ai Design canvas at
<https://claude.ai/artifact/CBwQLxxSJVoZAF45yEgh2Y>; agents that cannot open
it read the copies here. An earlier handoff lives in
[`docs/design/console/`](../../docs/design/console/README.md); this canvas is
the later approved design.

## How to use it

* Each `.dc.html` file holds one artboard's full HTML. Read it for the exact
  layout, copy, states and token values (the CSS custom properties on
  `.t-night` and `.t-dawn`), then rebuild the screen with the console's own
  components in `console/src/`.
* It is design source, never code to import or serve. Nothing in
  `console/` builds from this directory.
* The boards render only inside the canvas runtime (`./support.js`, which is
  not in the repository). Read them as plain HTML source:
  * `<helmet>` carries the fonts and the board's stylesheet;
  * `<x-dc>` holds the markup;
  * `{{name}}` bindings, `<sc-for list=… as=…>` loops and `<sc-if>`
    conditions are filled from the `renderVals()` of the
    `<script type="text/x-dc">` class at the bottom of the file, which is
    also where a prototype board's sample data and click behaviour live.
* [`canvas.json`](canvas.json) is the canvas index: each board's title,
  page, size and position, and the board order.
* `renders/` holds PNG renders of the component boards (Night theme). They
  are static HTML renders: the only bindings in those boards are the theme
  and a few form values, filled in by hand. The prototype boards have no
  renders, because their content is generated by the runtime.
